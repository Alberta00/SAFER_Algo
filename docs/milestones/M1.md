# Milestone: M1 — Deterministic Simulation Core

วันที่ตรวจ: 6 พฤศจิกายน 2026 (Asia/Bangkok)
สถานะ: implementation และ local correctness/reproducibility ผ่าน;
container acceptance ของ M0/M1 ยังติด Docker Engine storage ไม่ถือว่า milestone ทุก gate เขียวแล้ว

Implemented:
- Pure Python immutable Message/Category, queue lifecycle และ Scheduler Protocol
- FIFO, Strict Priority (EVENT → LIVE_STATE → HISTORY), EDF (+infinity สำหรับ non-event)
- Seeded workload สำหรับจำนวน devices ที่ config ได้, UUID/sequence และ payload distribution
- Link profiles S0–S6, simulation clock/event heap, piecewise bandwidth, latency/jitter/data loss/ACK loss
- Remote first-commit dedup model, late ACK, retry/backoff cap, overflow error และ no silent drops
- Event latency/deadline miss/censoring, per-key time-average AoI พร้อม coverage,
  restore-specific History target/completeness/recovery time, throughput/backlog/wait metrics
- CLI run/replay, JSON/CSV export, trace/config hashes, metadata แยกจาก deterministic output
- Tests ที่คำนวณมือและ CLI integration tests; ไม่มี network I/O หรือ mock metrics ในผล CLI

Open risks/known limitations:
- Memory queue/remote model ไม่ใช่ durable database; ยังไม่ทดสอบ real restart/crash/HTTP
- หนึ่ง in-flight request, ไม่มี protocol overhead/parallel transport; throughput ไม่เท่ากับ nominal link rate
- AoI first-delivery warmup อาจมี coverage ต่างกัน ต้องดู per-key coverage ประกอบ
- ยังไม่มี SAFER, matrix10seeds, CI remote, UI, resource measurements หรือผล hardware จริง
- ต้องแก้สถานะ Docker Desktop/WSL โดยเจ้าของแล้วรัน container checks ซ้ำ;
  ยังไม่ดำเนินการล้าง/reset/restart Engine ที่อาจกระทบงานอื่น
